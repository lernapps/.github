# Support

- **Using an app** (question, something looks wrong): use the report link at the bottom of the page, or open an issue in the app's repository.
- **Ideas, gaps, questions about lernapps:** open an issue in [lernapps/.github](https://github.com/lernapps/.github/issues/new/choose).
- **Security or privacy problem:** see [SECURITY.md](SECURITY.md). Please don't report it publicly.

lernapps is run by volunteers. We answer as soon as we can, but there is no guaranteed response time.
