# lernapps/.github

This repository holds everything that applies to the **lernapps** organisation as a whole:

- [`ORGANIZATION.md`](ORGANIZATION.md) – target structure of the org: repositories, ownership, naming and language rules, how apps connect to the platform, pipelines, governance, license, migration plan.
- `profile/README.md` – the org profile shown on <https://github.com/lernapps> (planned).
- Default community health files (CONTRIBUTING, CODE_OF_CONDUCT, GOVERNANCE, SECURITY, SUPPORT), issue forms and the PR template. They apply to every repo in the org that has none of its own (planned).

Work on the org structure is tracked as [issues and milestones](https://github.com/lernapps/.github/milestones) in this repository.

Owners: `@lernapps/maintainers`.
